# 🧮 Smart Calculator

A modern, responsive calculator built with **HTML, CSS, and JavaScript** as part of my **CodeAlpha Internship**.

The calculator provides a clean interface with essential arithmetic operations, calculation history, keyboard support, and a convenient copy-result feature.

## ✨ Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* `%` Percentage calculations
* `+/−` Positive/negative toggle
* 🔄 Clear and delete functions
* 📋 Copy calculation result
* 🕘 Calculation history
* ⌨️ Keyboard support
* 📱 Responsive design
* ♿ Accessible buttons and labels
* ⚡ Fast and lightweight

## 🛠️ Technologies Used

* **HTML5** — Structure and semantic markup
* **CSS3** — Styling, responsive layout, and visual effects
* **JavaScript** — Calculator logic and interactive functionality

To run the project locally:

1. Clone this repository.

3. Open `index.html` in your browser.
